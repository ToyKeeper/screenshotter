# Screenshotter tips / tricks / usage info / hotkey cheatsheet

Screenshot key: PrintScreen

Variants:  (configured in `~/bin/printscreen-*`)
  - Print / Screenshot key: take a pic, interactive by default
  - Shift: Fullscreen instead of interactive selection
  - Ctrl: Reuse previous title instead of asking
  - Meta: Also create a text file with more metadata (using a text editor)
  - ... combine the above as needed; all 8 combinations work.
